<p align="center"><b>A decentralized network where your identity is a key, not an account.</b></p>

Boson is a peer-to-peer network built on a hardened Kademlia DHT. Every user, device and
node is identified by its own Ed25519 key pair - no central registry, no certificate
authority, no password database. On top of the DHT, federated super nodes run Layer-2
services: messaging, object storage, a web gateway and an active proxy.

**Start here**

- **Build apps** - read the [documentation](https://docs.bosonnetwork.io). Java libraries are
  on Maven Central under `io.bosonnetwork`; Rust libraries are coming soon.
- **Run a super node** - a one-command install script and packages for Linux, macOS and
  Windows in [Boson.Releases](https://github.com/bosonnetwork/Boson.Releases).
- **See it in action** - [Photon](https://github.com/bosonnetwork/PhotonMessenger), a
  federated, end-to-end encrypted messenger built on Boson. Android today; iOS will follow
  the Rust libraries.

**Key repositories**

- [Boson.Core](https://github.com/bosonnetwork/Boson.Core) - core Java library: common APIs and the Kademlia DHT
- [Boson.Tools](https://github.com/bosonnetwork/Boson.Tools) - command line tools for developers and node operators
